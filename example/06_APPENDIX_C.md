# Приложение В. Контрольные запросы {#appendix-requests}

Запрос проверки доступности службы должен вернуть код 200.

```http
GET /health HTTP/1.1
Host: localhost:8080
```

Запрос с неизвестным путём должен вернуть код 404.

```http
GET /missing HTTP/1.1
Host: localhost:8080
```

Различие кодов ответа подтверждает, что служба доступна и обрабатывает только
зарегистрированные маршруты.
